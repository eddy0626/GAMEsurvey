# Claude Code 작업 프롬프트 — 플레이테스트 리포트 자동화

CMD에서 `claude` 실행 후 아래 내용을 붙여넣는다.
아래 **[메인 프롬프트]** 하나만 먼저 주고, 작업이 끝날 때마다 **[Phase N 후속]** 을 이어서 준다.

## 시작 전 준비

작업 폴더를 새로 만들고 아래 파일을 넣은 뒤 그 폴더에서 `claude` 를 실행한다.

```
playtest-report-automation\
  ├─ 참조\
  │   ├─ 플레이테스트_리포트_자동화_설계안.docx      ← 전체 설계
  │   ├─ 미스트월드_플레이테스트_결과리포트.docx      ← 목표 산출물 (수작업 기준선)
  │   ├─ 2026_플레이테스트_구글폼_복붙용.md          ← 5개 폼 전체 문항 정의
  │   ├─ survey_data.py                            ← 문항 단일 원본
  │   ├─ report_data.py                            ← 15명 예시 응답 데이터
  │   ├─ gen_report.py                             ← 리포트 조립 로직 (파이썬 버전)
  │   └─ 「미스트월드」 플레이테스트 설문 (응답).xlsx   ← 실제 응답 시트 구조
  └─ (여기에 Claude Code가 작성)
```

## [메인 프롬프트]

```
너는 Google Apps Script 개발자다. 구글 폼 설문 응답에서 리포트를 자동 생성하는
시스템을 만든다. 아래 내용을 끝까지 읽고 Phase 1만 먼저 작업한다.

## 배경

2026 충북 인디게임 플레이테스트 사업이다. 인디게임 5종을 교육 수강생 14명과
전문가 2명이 각각 15분씩 플레이하고 구글 폼으로 설문에 답한다.
게임 5 × 응답자 16 = 총 80건의 응답이 게임별 구글 시트 5개에 쌓인다.

지금은 이 응답을 사람이 직접 집계해 리포트를 쓴다. 게임 1개에 하루가 걸린다.
이걸 시트 메뉴 버튼 하나로 자동화하는 것이 목표다.

## 만들 것

1. 개별 응답 카드 80건 — 응답자 1명 × 게임 1개당 1건, 1~2페이지
2. 게임별 종합 리포트 5건 — 게임 1개당 1건, 12~15페이지
3. 응답 현황 대시보드 1개 — 시트 안에서 실시간 확인

모두 구글 문서로 만들고 PDF로도 변환해 같은 폴더에 저장한다.

## 반드시 지킬 기술 제약

1. Apps Script 실행 시간 제한 6분
   문서 85건을 한 번에 만들면 초과한다. 반드시 배치로 나눈다.
   - 한 번에 20건씩 처리
   - 진행 위치를 PropertiesService에 저장
   - 남으면 ScriptApp 시간 트리거로 이어서 실행
   - 완료된 트리거는 즉시 deleteTrigger 로 제거 (동시 트리거 20개 상한)
   - 실행 시작 시각을 기록해 5분 경과하면 스스로 중단하고 다음 트리거 예약

2. 레이더 차트
   Apps Script에는 차트 생성 기능이 없다. 외부 API도 쓰지 않는다.
   구글 시트가 레이더 차트(Charts.ChartType.RADAR)를 기본 지원하므로
   숨김 시트에 데이터를 쓰고 차트를 만든 뒤
   chart.getBlob() 또는 getAs('image/png') 로 이미지를 얻어 문서에 삽입한다.
   차트 객체는 사용 후 반드시 removeChart 로 정리한다.

3. 디자인은 템플릿 문서에서 관리
   문서 서식을 코드에 하드코딩하지 않는다.
   구글 문서 템플릿에 {{게임명}} {{응답자ID}} 같은 자리표시자를 넣고,
   DriveApp 으로 템플릿을 복사한 뒤 body.replaceText 로 치환한다.
   담당자가 코드를 몰라도 템플릿 문서만 고쳐 서식을 바꿀 수 있어야 한다.

4. 응답 시트를 절대 수정하지 않는다
   원본 응답은 읽기만 한다. 집계는 별도 시트에 쓴다.

## 응답 시트 구조

폼마다 문항이 다르지만 앞 6개와 뒤 16개는 5개 폼이 동일하다.
미스트월드 기준 열 구성(0부터):

0  Timestamp
1  이름을 적어 주세요.                          ← 개인정보, 리포트에 노출 금지
2  (동의) 게임 정보 비공개·무단사용 금지
3  (동의) 응답 활용
4  연령대                    → 10대 / 20대 / 30대 / 40대 이상
5  성별                      → 남성 / 여성 / 응답하지 않음
6  선호 장르 (체크박스, 쉼표 구분)
7~16   게임별 고유 문항 (개수가 폼마다 다름: 10 / 10 / 13 / 5 / 16)
17 재미            ┐
18 조작성          │
19 그래픽 · 아트    │ 육각형 6축, 1~5점 선형배율
20 몰입도          │ 이 순서를 절대 바꾸지 않는다
21 완성도          │
22 정식 출시 기대감 ┘
23 진행 흐름                1~5점
24 기술 안정성              1~5점
25 진행도                   5단계 객관식
26 개선되었으면 하는 점       서술형
27 스팀 구매 의향            5단계 객관식
28 적정 가격                6구간 객관식
29 추천 의향                0~10 선형배율 (NPS)
30 버그 경험                4단계 객관식
31 버그 상황                서술형
32 개발팀에 전하고 싶은 말    서술형

열 위치를 인덱스로 하드코딩하지 말고 헤더 텍스트로 찾아 매핑한다.
문항이 바뀌어도 Config 의 매핑 표만 고치면 되게 만든다.

## 산출물 상세

### 개별 응답 카드 (80건)
- 파일명: 「게임명」_P01_응답카드
- 응답자 이름 대신 P01~P16 형식 ID 사용. 이름-ID 대응표는 접근 제한 시트에 따로 보관
- 구성: 머리말(게임명·ID·제출일시·응답자유형) / 응답자 정보 / 육각형 차트(본인 vs 전체평균 겹쳐 표시)
  / 선택형 응답 표 / 서술형 4개 전문 / 요약 한 줄
- 해석·평가 문장은 넣지 않는다. 원문 그대로 보여주는 문서다

### 게임별 종합 리포트 (5건)
참조/미스트월드_플레이테스트_결과리포트.docx 와 같은 구조로 만든다.
이 파일이 목표 산출물이자 검증 기준선이다. 먼저 열어서 구조를 파악할 것.

한눈에 보기 → 1.테스트개요 → 2.정량결과 → 3.핵심발견 → 4.세그먼트분석
→ 5.개선권고 → 부록A(문항별집계) 부록B(자유서술원문) 부록C(응답자별점수)

3장 핵심 발견은 완전 자동 생성하지 않는다.
아래 규칙으로 "이슈 후보"를 뽑고 근거 인용을 자동으로 붙인 초안까지만 만든다.
담당자가 취사선택하고 권고 문장을 쓴다.

   - 게임이 추가됐을 때 고치는 곳
   - 자주 나는 오류와 대처
```

## 참고 — clasp 를 쓸 경우

Claude Code가 만든 .gs 파일을 매번 복사해 붙여넣기 번거로우면 clasp로 자동 배포한다.

```
npm install -g @google/clasp
clasp login
clasp create --type sheets --title "플레이테스트 리포트 자동화"
clasp push          # 로컬 → Apps Script 업로드
clasp open          # 브라우저에서 열기
```

이 경우 메인 프롬프트 끝에 아래를 덧붙인다.

```
이 프로젝트는 clasp 로 관리한다. .clasp.json 과 appsscript.json 을 함께 만들고,
파일을 수정한 뒤에는 clasp push 명령을 알려줘라. 직접 실행하지는 마라.
```

## 프롬프트를 줄 때 주의할 점

- **한 번에 전부 주지 않는다.** Phase 1만 먼저 주고 결과를 보고 이어간다.
  전체를 한 번에 시키면 검증 없이 6개 파일이 쏟아져 나와 어디가 틀렸는지 찾기 어렵다.
- **템플릿 문서는 사람이 만든다.** Claude Code는 구글 드라이브에 접근할 수 없다.
  자리표시자 목록을 받아 직접 문서를 만들고 ID를 알려줘야 한다.
- **실제 응답 시트 ID가 필요하다.** Config.gs 작성 시 시트 ID를 물어보면 알려준다.
- **Phase 4가 가장 오래 걸린다.** 종합 리포트는 표와 차트가 많아 한 번에 안 끝난다.
  장 단위로 나눠 지시하는 편이 낫다.
