# 설문 조사 데스크탑 앱 — 설계

2026-08-15

## 무엇을 만드나

2026 충북 인디게임 플레이테스트 현장에서 쓸 데스크탑 앱이다.
참가자가 게임을 15분 플레이한 뒤 그 자리에서 설문에 답하고, 그 응답으로
개별 카드와 종합 리포트를 만든다. 구글 폼을 완전히 대체한다.

## 정해진 것

| 항목 | 결정 |
|---|---|
| 앱의 역할 | 응답 수집 + 리포트 생성. 한 앱에 화면 두 개 |
| 구글 폼 | 쓰지 않는다. 앱이 완전히 대체한다 |
| 운영 형태 | 게임별 PC 5대에 설치. 플레이 직후 그 자리에서 응답 |
| 응답 취합 | 각 PC 로컬 저장 → USB 로 모아 담당자 PC 에서 합친다 |
| 화면 보호 | 없다. 참가자도 모든 탭에 들어갈 수 있다 |
| 기술 | 파이썬 + pywebview (화면은 HTML/CSS, 속은 파이썬) |
| 대상 PC | Windows 10/11 최신. WebView2 기본 탑재 |

## 화면

### 참가자 쪽

```
① 대기        「미스트월드」 플레이테스트
              [ 설문 시작하기 ]
              오늘 받은 응답 12명

② 이름 고르기  명부 16명을 타일로. 이미 응답한 사람은 흐리게 + 체크
              [ 명단에 없어요 ] → 직접 입력

③ 설문        섹션별로 넘긴다. 구글 폼과 같은 순서:
              참여 동의 → 시작하기 전 → 게임 문항 → 게임 전체 평가 → 종합 의견
              상단 진행 막대. 필수 문항 미응답이면 다음으로 못 넘어간다

④ 완료        감사 문구 → 5초 뒤 자동으로 ①로 복귀
```

이 PC 가 어느 게임인지는 최초 1회만 설정한다. 그 뒤로 참가자가 게임을 고를 일이 없다.

### 진행자 쪽 (같은 앱, 상단 탭)

- **현황** — 이 PC 응답 목록, 미응답자, 응답 하나 열어 보기, 삭제
- **모으기** — USB 로 가져온 다른 PC 응답 폴더를 불러와 합치기
- **리포트** — 합쳐진 응답으로 문서 85건 생성

## 데이터 흐름

```
참조/survey_data.py ──(빌드 시 추출)──▶ app/web/survey.json ──▶ 앱이 문항을 그린다

응답 1건 ──▶ 응답/G01_20260820_143012_P05.json        개별 파일
                    │
              [모으기] 여러 PC 것을 한 폴더로
                    │
                    ▼
              data/응답/01_미스트월드.csv               구글 폼 시트와 같은 형식
                    │
                    ▼
              기존 py/ 파이프라인 그대로 ──▶ 문서 85건
```

**핵심 제약** — 앱이 내보내는 CSV 는 구글 폼 응답 시트와 형식이 같아야 한다.
헤더도 `1. 이름을 적어 주세요.` 처럼 번호 접두사까지 그대로다.
그래야 `py/ingest.py` 아래로는 한 줄도 고치지 않고 쓸 수 있다.
이미 448개 검증을 통과한 코드다.

응답을 개별 JSON 으로 남기는 이유는 두 가지다.
USB 로 모을 때 파일만 복사하면 되고, 같은 사람이 두 번 제출해도
파일이 따로 남아 나중에 골라낼 수 있다.

## 저장 형식

### 응답 파일 `응답/G01_20260820_143012_P05.json`

```json
{
  "게임코드": "G01",
  "제출시각": "2026-08-20 14:30:12",
  "이름": "김도현",
  "ID": "P01",
  "유형": "교육생",
  "앱버전": "1.0",
  "답": {
    "N1": "김도현",
    "A3": ["RPG", "전략 · 턴제"],
    "D1": 4,
    "E2": "인벤토리 커서 위치를 기억해 주세요."
  }
}
```

답은 문항 ID 를 키로 쓴다. 체크박스는 배열, 선형배율은 숫자, 나머지는 문자열.

### 이 PC 설정 `settings.json`

```json
{ "게임코드": "G01", "기관명": "충북글로벌게임센터", "자동복귀초": 5 }
```

### 임시 저장 `응답/_작성중.json`

문항에 답할 때마다 덮어쓴다. 제출하면 지운다.
앱을 다시 열었을 때 이 파일이 있으면 이어서 할지 묻는다.

## 파일 구조

```
app/
  main.py          진입점 — 창 띄우기, 설정 로드
  api.py           JS ↔ 파이썬 다리 (pywebview js_api)
  store.py         응답 저장 · 읽기 · 합치기 · CSV 내보내기
  settings.py      이 PC 설정 읽고 쓰기
  web/
    index.html
    app.css
    app.js
    survey.json    빌드 시 생성
tools/
  make_survey_json.py   survey_data.py → survey.json
```

`api.py` 는 화면이 부르는 함수만 노출한다. 실제 일은 `store.py` 와
기존 `py/` 모듈이 한다. 화면은 파이썬 내부를 모른다.

## API (화면이 부르는 것)

| 함수 | 하는 일 |
|---|---|
| `설정()` / `설정저장(d)` | 이 PC 게임 코드 등 |
| `설문(게임코드)` | 그 폼의 섹션 · 문항 정의 |
| `명부()` | 이름 · ID · 유형 · 이 게임에 응답했는지 |
| `임시저장(부분)` / `임시불러오기()` / `임시삭제()` | 작성 중 응답 |
| `제출(응답)` | 파일로 저장하고 임시 삭제 |
| `응답목록()` / `응답삭제(파일명)` | 현황 탭 |
| `폴더합치기(경로)` | USB 로 가져온 응답 폴더 |
| `CSV내보내기()` | `data/응답/*.csv` 생성 |
| `리포트생성()` | 기존 파이프라인 호출 |

## 오류 처리

- **명부 파일이 없다** — 이름 직접 입력으로 떨어진다. 앱은 계속 돈다.
- **응답 저장 실패(디스크·권한)** — 화면에 그대로 띄우고 재시도 버튼. 임시 파일은 안 지운다.
- **중복 제출** — 같은 게임에 같은 ID 가 이미 있으면 확인을 묻고, 승낙하면 둘 다 남긴다. 골라내는 것은 담당자 몫.
- **합치기 중 같은 파일명** — 내용이 같으면 건너뛰고, 다르면 뒤에 `_2` 를 붙인다.
- **리포트 생성 중 Word 가 파일을 잡고 있다** — 기존 `run.py` 처럼 건너뛰고 무엇이 안 됐는지 모아 보여 준다.

## 검증

- `tools/make_survey_json.py` 가 뽑은 문항 수 · 순서가 `survey_data.py` 와 같은지
- 앱이 내보낸 CSV 를 `py/ingest.py` 로 읽었을 때 **공통 문항 누락 0 · 열 수 33/33/36/30/40**
- 더미 응답을 앱 형식으로 만들어 CSV 로 내보내고 문서 85건이 나오는지
- 기존 검증 448 + 91 이 그대로 통과하는지 (파이프라인을 안 건드렸으므로)

## 하지 않는 것

- 클라우드 동기화 · 서버 · 계정
- 실시간 다중 PC 현황 취합 (USB 회수로 충분)
- 설문 문항을 앱에서 편집하는 기능 (`survey_data.py` 가 단일 원본)
- 화면 잠금 · 권한 분리
